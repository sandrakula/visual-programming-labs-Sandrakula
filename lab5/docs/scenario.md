# Сценарий `lab5-sandrakula-faq`

## Основа

Использован готовый шаблон **FAQ** из галереи Typebot. Исходный шаблон был
англоязычным и посвящён сервису веб-аналитики Analyzr.

## Изменения

1. Название заменено на `lab5-sandrakula-faq`.
2. Приветствие, описание, меню и кнопки переведены на русский язык.
3. Добавлена переменная `student_group` со значением `СДП-ИИ-241`.
4. Добавлен блок Condition: `student_group = СДП-ИИ-241`.
5. Добавлен HTTP Request:
   `GET https://httpbin.org/get?lab=5&student=sandrakula`.
6. Тема заменена на **Aqua Glass**.

## Диалог

- «Что умеет бот?» — описание возможностей FAQ-бота.
- «Как выполнена работа?» — описание выбранного шаблона и изменений.
- «Какие технологии изучены?» — переменные, условия, ветвление и HTTP.
- «Задать другой вопрос» — ввод произвольного вопроса.

## Проверка

Позитивная ветка условия срабатывает при значении `СДП-ИИ-241`. Ветка `Else`
служит fallback для любого другого значения. HTTP Request не передаёт секретов
и обращается к тестовому сервису `httpbin.org`.
