# Инструкция для демонстрации лабораторной работы №2

## Задание 2.1 — Inject → Debug

1. В каталоге репозитория выполнить `docker compose -f lab2/docker-compose.yml up -d`, затем открыть [http://localhost:1880](http://localhost:1880).
2. В верхней части редактора открыть вкладку **«2.1 — Inject Debug»**.
3. Справа открыть панель **«Отладочные сообщения»** (значок жука). Поток уже работает по таймеру; для дополнительной ручной проверки можно нажать квадратную кнопку слева на ноде Inject.
4. В Debug должны появляться новые полные объекты `msg` каждые 5 секунд. Проверить `payload: "Sandrakula"` и `topic: "lab2/Sandrakula/basic"`.
5. Краткое объяснение преподавателю: Inject формирует сообщение по таймеру, записывает строку в `msg.payload` и тему в `msg.topic`, затем передаёт объект по соединению; Debug получает его и показывает весь объект `msg`, включая служебный `_msgid`.

Для быстрого подтверждения версий показать [00-nodejs-version.png](../screenshots/00-nodejs-version.png), а для подтверждения работы потока — [01-inject-debug.png](../screenshots/01-inject-debug.png).
